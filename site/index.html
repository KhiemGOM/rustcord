Not a toy

The Discord you use every day.

Built against live captures of Discord's own client, down to its colours, spacing and keyboard shortcuts.

Chat and navigation

  • Servers, folders, DMs, group DMs, threads and forums
  • Markdown, replies, forwarding, pins, polls, scheduled messages
  • Custom emoji, stickers, reactions, GIF picker, inline players
  • Search, the Ctrl+K quick switcher and Discord's shortcuts
  • Slash commands, bot buttons and select menus

Voice, video and streaming

  • Voice channels, DM and group calls, stage channels
  • DAVE end-to-end encryption for audio and video
  • Go Live with Gaming, Screenshare and Custom modes
  • Watch streams and webcams, first frame in 1.3–2.2 s
  • Soundboard, clips, push-to-talk, per-device audio

Profiles, themes and settings

  • All 24 settings pages, with a searchable sidebar
  • Light, Ash, Dark, Onyx, Sync, Nitro and custom themes
  • Per-server profiles, profile themes, display name styles
  • Server settings: roles, channels, AutoMod, members
  • Global keybinds and Streamer Mode

Accounts and extras

  • Log in with password and 2FA, passkey, QR code or token
  • Local cache, so warm starts paint before the gateway connects
  • Activities and video embeds through WebView2
  • Shop, Orbs wallet, Quests and Discover
  • Friends, status picker, saved messages and reminders
What about Phoenix?

Discord is rewriting its app in Rust too.

Project Phoenix, Discord's own desktop rewrite on Rust and Zed's GPUI, was previewed at around 290 MB in Task Manager. There's no public beta or release date yet. When it ships it will be official, supported and cross-platform.

Until then, or if you want a client you can read and build yourself, Rustcord runs on Windows today.

FAQ

Before you download.

Can my account get banned?

It can. Rustcord is unofficial, and third-party clients are against Discord's Terms of Service; Discord can suspend or ban accounts that use one. Rustcord identifies itself to Discord as the official desktop client so features work. Use it at your own risk, and consider a secondary account.

Windows says it protected my PC. Is that normal?

Yes. The exe isn't code-signed, so SmartScreen warns the first time. Click More info, then Run anyway. Each release is built by CI from a signed tag and ships with rustcord.exe.sha256, so you can check the file you got, or build it yourself with cargo run --release.

What do I need to run it?

Windows 10 or 11, 64-bit. Activities and video embeds use WebView2, which comes with Windows 11 and current Windows 10. There's no installer: download rustcord.exe or the zip and run it.

Do I lose my login when I update?

No. Your login and the cached servers, channels and recent messages live in %LOCALAPPDATA%\Rustcord. Replace the exe and they carry over.

Is it really open source?

Yes, dual-licensed MIT or Apache-2.0, on GitHub along with the harness that measured the numbers on this page. It doesn't bundle Discord's icons, fonts or sounds; like Discord's web client, it fetches them from discord.com on first launch.

Why only Windows?

It's built straight on Direct3D 11 for drawing, WASAPI for audio and WebView2 for Activities and embeds. Going native on one platform is how it stays one 32.7 MB exe with no cross-platform runtime.

One exe. Nothing to install.
